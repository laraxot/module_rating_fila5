# 18.56 — Accessor `ratings_by_id` per esportazione ratings con titolo

## Perché
`data_get($record, 'ratings.3.value')` fallisce perche' `ratings` e' indexed per posizione (0..N), non per `id`. L'accessor `ratings_by_id` (keyBy('id')) permette `data_get($record, 'ratings_by_id.52.pivot.value')`.

## Accettazione
- [x] `HasRatingsTrait::getRatingsByIdAttribute()` restituisce collection keyed per `id`
- [x] `HasRatingsTrait::ratingValuePath()` restituisce `ratings_by_id.{id}.pivot.value`
- [x] `IndennitaResponsabilita::getXlsFields()` usa `ratingValuePath()` per generare chiavi
- [x] `CollectionExport` e `XotBaseExporter` estraggono con `data_get()` sullo stesso percorso
- [x] Test `HasRatingsTraitRatingsByIdTest` verde

## Note per continuare
Se si modifica la relazione `ratings()` (es. da `morphToMany` a `hasMany`), `keyBy('id')` potrebbe non funzionare: verificare `getKeyName()` sul model Rating.
