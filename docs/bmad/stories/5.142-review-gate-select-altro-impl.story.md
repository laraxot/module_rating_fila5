### Test

- [x] **PASS** — Pest `selectIsOther` diretto: `null` → `false`, `''` → `true`, id figlio → `false` (test su valore già risolto, non su `Get` — vedi nota metodologica sotto)

**Nota metodologica sul test "null → non required":** `Textarea::isRequired()` valuta il closure
tramite `Get`, che richiede un componente agganciato a un container Filament live
(`Component::$container must not be accessed before initialization` fuori da quel contesto) —
non testabile in isolamento senza costruire un form Livewire reale. La copertura equivalente,
corretta e più diretta, è sulla funzione pura che quel closure chiama (`selectIsOther`), che
riceve esattamente lo stesso identico valore che `$get($field)` avrebbe restituito.
