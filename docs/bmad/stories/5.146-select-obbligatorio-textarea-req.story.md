# Story Rating/5.146 — Select obbligatorio + Textarea obbligatoria se seleziona altro

## Perché

**Utente:** *il select deve essere obbligatorio; se seleziono 'altro', la textarea deve essere obbligatoria*

Attualmente, il componente Select in `HasRatingsTrait::buildRatingComponent` ha `->nullable()` (non obbligatorio) e manca una regola di validazione che lo renda obbligatorio. La Textarea è obbligatoria solo quando il select è `''` (altro), ma l'UI consente di non selezionare nulla (stato null) che l'utente segnala come confuso.

Questa story registra la **regola** e le **azioni di estrazione** per implementare:

1. **Select:** aggiungere `->required()` (inoltre alla regola di validazione esistente) in modo che l'utente debba scegliere un'opzione — l'opzione '' (altro) è consentita.
2. **Textarea:** mantenuta come attualmente obbligatoria solo quando il select è `''` (`selectIsOther`).
3. **Leggibilità dell'errore:** assicurarsi che il campo Select abbia un `validationAttribute` leggibile (l'altro agente lavora su `validation-attribute-readable`, status: bloccato).

## Perché è un problema per gli host

- IndennitaResponsabilita (CompilaIndennitaResponsabilita) dipende dal fatto che il select abbia un valore (altrimenti il bug della nota "obbligatorio" per il select non si manifesta).
- Tutti gli host consumano `HasRatingsTrait::buildRatingComponent` — un cambiamento di comportamento in un unico posto porta un'affinità per tutti.
- La regola BMAD evita il blocco: il componente del trait decide i campi dei rating in modo indipendente.

## Scenari di successo

- Il componente Select ha `->required()` aggiunto.
- Il componente Select mantiene il placeholder (bozza) e l'opzione '' (altro).
- La Textarea è obbligatoria solo quando il select è `''` (altro) — come attualmente definito in `selectIsOther()`.
- Messaggi di errore di validazione leggibili (es. "Campo richiesto" su select; "Nota obbligatoria per 'altro'" su Textarea).
- Pest include un test per il select obbligatorio (il test esistente `selectIsOther` può essere ampliato per testare la regola required).
- Vengono aggiornati i test in `HasRatingsTraitAltroOptionTest.php` (bloccati; aggiornati dopo lo sblocco).
- Vengono aggiornate le storie BMAD di IR (IndennitaResponsabilita/5.140) per riflettere i cambiamenti di comportamento.
