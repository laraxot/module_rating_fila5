## Perché

Utente: migliorare UI/UX Select+Textarea con Filament 5 `Section` invece di `Fieldset`.

## Canon invariato

- Select + Textarea **sempre** visibili
- `OTHER_OPTION_KEY = ''`; note required solo se `selectIsOther`
- Trait non setta heading/label (D-1); host → `heading($label)`

## Cambio fatto

| Prima | Dopo |
|-------|------|
| `Fieldset::make()->schema([...])` | `Section::make()->columns(2)->compact()->schema([...])` |
| Host `instanceof Fieldset` → `label()` | Host `instanceof Section` → `heading()` |
