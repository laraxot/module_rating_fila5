## Perché

Utente: textarea **sempre** affianco al select; blocco a 2 campi **occupa 2 colonne**;
ok Fieldset o Section — scelta **Fieldset**.

## Spec applicata

```php
return Fieldset::make()
    ->columnSpan(2)
    ->schema([$select, $note]); // columns(2) da setUp; nessun ->visible() sulla note
```
