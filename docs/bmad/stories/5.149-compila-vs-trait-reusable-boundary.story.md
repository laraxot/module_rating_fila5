# Story Rating/5.149 — pezzi riutilizzabili, non tutto

## Perché

Utente: in `CompilaIndennitaResponsabilita.php` ci sono cose che **probabilmente**
dovrebbero stare in `HasRatingsTrait` — pezzi riutilizzabili, BMAD + second brain.

Non significa spostare tutto: significa **separare generale e particolare** (canon 5.92 / 5.147).

## Mappa attuale (post-5.147)

| Pezzo in Compila | Dove vive | Motivo |
|------------------|-----------|--------|
| `hydrateRatingsFormData` / `syncRatingsFormData` | **trait** ✅ | Ogni host fill/save stesso pivot value+note |
| `getRatingsFormSchema` / `buildRatingComponent` / Fieldset | **trait** ✅ | Schema da righe `ratings` |
| `getRatingsWhere` / `ratingFormFields` / `ratingFieldName` | **trait** ✅ | Query e naming |
| `getRatingsForYear()` thin wrapper | host OK | Nome dominio IR; delega già al trait |
| `decorateRatingField` — label Fieldset/Field | **→ estraibile** | Stesso pattern per ogni host Filament |
| `decorateRatingField` — TextEntry + money su «Importo» | **host** | Difetto noto IR (`18.49`); non piattaforma |
| `recalculate*` / `getTot` / `getImporto*` | **host** | Economia IR (part-time, ×10, ×12) |
| `ensureMinimumPositiveRatings` | **host** | Soglia + copy IR; YAGNI senza 2° consumer |
| `infolist` matr/cognome/nome | **host** | Dominio scheda IR |
| `dal`/`al`/`note` form + save only | **host** | Colonne modello IR |
| Gate `compila`, back Action | **host** | Auth/UX pagina |

## Estrazione di questo giro (KISS)

1. **`HasRatingsTrait::formFieldLabel(BaseRating): string`**  
   Convenzione form: `strip_tags(txt ?? title)`. Diversa da `BaseRating::getLabel()` (albero/`title` only).

2. **`Modules\Rating\Filament\Concerns\DecoratesRatingFormFields`**  
   Trait per **page** Filament (non modello): applica label a `Fieldset` e `Field` (columns 2, helperText '').  
   Non tocca TextEntry/money — resta override host.

3. Compila: `decorateRatingField` = ramo money IR + `applyDefaultRatingFieldDecoration(...)`.

## Cosa NON si estrae (ribadito)

- Calcoli economici, soglia minima criteri, infolist anagrafica, Gate.
- `Str::studly($title)` → dispatch metodi: promuoverlo a trait ripete l’anti-pattern 5.91/5.92.
