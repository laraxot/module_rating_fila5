# Story Rating/5.152 — note required on «altro» (bug reale)

## Perché

Utente: seleziono «altro» ma la Textarea **non** è obbligatoria — richiesto da tempo;
i test esistenti verificavano solo `instanceof Closure`, non il comportamento.

## Root cause (verificata)

1. Select con figli applicava ancora `->rules(RuleEnum)` tipo `numeric|min:0|max:5`.
   Valore sentinella `other` **non è numeric** → validazione Select falliva prima
   che la note potesse risultare obbligatoria.
