# Story Rating/5.156 — Select required + note on «altro» (Get path fix)

## Perché

Utente: *il select deve essere obbligatorio, se selezioni altro deve essere obbligatoria
la textarea*.

Il Select aveva già `->required()` e `Rule::in` (5.152), ma la note **non** scattava a
runtime su Compila (`statePath('data')`).

## Root cause

`->required(fn (Get $get) => selectIsOther($get($field, isAbsolute: true)))` risolva il
path come `ratings.{id}.pivot.value` **senza** il prefisso `data.` del form → Get non
trova il Select → `null` → `selectIsOther` false → Textarea mai obbligatoria.

## Fix

```php
$select = Select::make($field)->required()->rules([Rule::in(...)])->live()...;
$note = Textarea::make(...)->required(
    static fn (Get $get): bool => self::selectIsOther($get($select)) // Component!
);
Fieldset::make()->markAsRequired()->columnSpan(2)->schema([$select, $note]);
```

`$get($select)` usa lo statePath reale del componente (incl. `data.`).
