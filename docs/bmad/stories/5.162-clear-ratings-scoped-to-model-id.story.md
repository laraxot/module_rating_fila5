# Story Rating/5.162 — Svuota/sync scoped a un solo record

## Perché

Utente 2026-09-16: «hai ucciso tutti i record !! dovevi solo azzerare quelli
riferiti a quel record !!»

`rating_morph` ha due forme di `model_type` (alias `indennita_responsabilita` e
FQCN). `updateExistingPivot` via `ratings()` vede **solo** l'alias. Effetti:

1. i dati reali spesso stanno sul FQCN e restano orfani / inconsistenti
2. al reload, `syncRatingsWhere` + `js(reload)` creava pivot alias **vuoti**
3. rischio percepito di wipe globale se lo scope non e' esplicito su `model_id`

## Fix (aggiornato)

1. `HasRatingsTrait::clearEvaluation()` — `ratingMorphs()->update([value=>null, note=>null])`
   sul **solo** `model_id` corrente (alias+FQCN). Niente `delete()`, niente attach.
2. `clearRatingsFormData()` — alias BC che delega a `clearEvaluation()`
3. Page Compila: header Svuota → chiama `$record->clearEvaluation()` + hydrate UI
4. Blade: Svuota solo header; Indietro|Salva in barra; `<br/><br/>` prima/dopo blocco basso
