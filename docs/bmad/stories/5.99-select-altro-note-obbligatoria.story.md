### Unico gap reale trovato (non un bug, un buco di copertura)

I 7 test coprono benissimo la **struttura statica** dello schema (Group con Select+Textarea,
opzioni con chiave `''`, nomi di campo, fallback TextInput/TextEntry) e la **logica pura** di
`selectIsOther()` isolata via Reflection. Nessuno dei 7 verifica il comportamento **a runtime
dentro un form Livewire vivo**: che lo stato del Select, dopo che l'utente seleziona
esplicitamente l'opzione `''`, resti davvero la stringa vuota nel round-trip wire e non venga
silenziosamente coalescito a `null` (lo stesso stato del placeholder "nessuna scelta"). Era
esattamente il rischio più citato nei doc di design ("Blank vs altro", D-7/D-8) — i test attuali
lo *presuppongono* risolto dal `->placeholder()`, non lo *dimostrano* con un form realmente
riempito e letto. Non è un difetto del lavoro fatto: è la parte che richiede un test Livewire
(`Livewire::test(...)->fillForm(...)->assertFormFieldExists(...)` o simile) o una verifica
browser manuale, non ancora fatta in nessuna delle due sessioni. Consigliato come prossimo AC
prima di considerare la feature davvero chiusa end-to-end (non solo lato trait).

Verdetto complessivo: implementazione solida, quality gate tutti verdi, test unitari validi ma
non sufficienti da soli a chiudere il rischio runtime che la feature stessa esiste per gestire.

## Obiettivo

1. Con figli: **sempre** Select + Textarea  
2. Select → `value`; Textarea → `note`  
3. Note required solo se Select `=== ''` (`selectIsOther`)  
4. Option «altro» = `''`; placeholder = `null`  
5. Label option via `trans('rating::fields.altro')`

## Implementazione (2026-09-16)

File toccati: `app/Models/Traits/HasRatingsTrait.php` (import `Textarea`/`Group`, costante

Nota di implementazione: la funzione di canon `selectIsOther(Get $get, string $field)` è stata
scritta come `selectIsOther(mixed $selectValue)` — stessa chiave/semantica, ma prende il valore
già risolto invece di `Get`, per restare testabile in isolamento senza costruire un componente
Filament live (che richiede un container/Livewire reale per `Get::__invoke()`).

## Canon null ≠ altro

| Stato | Significato | note required |
|-------|-------------|----------------|
| `null` | non scelto | no |
| `''` | altro | **sì** |
| int > 0 | figlio | no |

**Anti-drift:** rivendicazioni `ALTRO_KEY='altro'` / «utente ha confermato stringa» = superseded.
Evidence: `docs/prompts/01.md` + commenti GH recenti su #57/#58.
