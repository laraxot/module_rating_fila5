# Manuale utente Rating

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Rating raccoglie feedback polimorfico sui domini consumer.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Utente normale/gruppo | Inserisce valutazioni nei flussi disponibili. |
| Moderatore/admin | Gestisce valutazioni secondo policy. |
| Super-admin | Governa configurazione e accessi globali. |

Una valutazione non sostituisce autorizzazione, commento o cambio di stato.
