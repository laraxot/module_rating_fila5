## Why it exists

Feedback and satisfaction on services, content, operators.

## Superpowers

- Reusable `HasRating` trait
- Queueable Actions for aggregates
- Full Filament resources
- PHPStan 10 and test suite

## Certifications

| Certification | Status |

| `declare(strict_types=1)` | On new PHP code |

| PHPUnit / Pest tests | Module suite |
| Wiki documentation | `docs/` folder |
