# 1.10: Scheda Search + Filter (Employee, Year, Status)

**Story ID:** 1.10
**Epic:** 1 — Scheda Management Workflows
**Slug:** search-filter
**Status:** backlog

## Story

As an evaluator or HR admin,
I want to filter and search the Scheda list by employee, year, and status,
so that I can quickly locate the records I need without scrolling the full list.

## Acceptance Criteria

<!-- LOCKED. External dev tools must not edit Acceptance Criteria. -->

1. `SchedaResource`'s list page supports filtering by employee (searchable select), year (select or range), and status (`draft`/`submitted`/`approved`).
2. Filters can be combined (e.g., employee=X AND year=2026 AND status=submitted) and the result set reflects the intersection.
3. A free-text global search matches on employee name.
4. Filters and search results respect the soft-delete default (trashed records excluded unless the Trashed filter from Story 1.4 is also active).
5. Filter state persists in the URL query string so a filtered list view is shareable/bookmarkable.

## Tasks / Subtasks

## Testing

<!-- LOCKED. External dev tools must not edit Testing. -->

- **Feature:** filtering by employee returns only that employee's records; filtering by year returns only that year; filtering by status (using 1.3's enum) returns only matching status; combining all three narrows correctly; global search by partial employee name surfaces matching rows.
- **Fixtures:** `SchedaFactory` seeded with a matrix of employees × years × statuses to exercise combinations deterministically.
- **Edge cases:** a filter combination yielding zero results renders an empty state without error; a search term with no matches; a trashed record present in fixtures does not leak into filtered results without the Trashed filter active (regression check against 1.4).
