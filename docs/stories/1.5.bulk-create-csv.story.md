# 1.5: Bulk Create From CSV

**Story ID:** 1.5
**Epic:** 1 — Scheda Management Workflows
**Slug:** bulk-create-csv
**Status:** backlog

## Story

As an HR admin,
I want to import Scheda records in bulk from a CSV file (or clone the prior year's records),
so that I can seed evaluations quickly instead of entering them one by one.

## Acceptance Criteria

<!-- LOCKED. External dev tools must not edit Acceptance Criteria. -->

1. HR admin can upload a CSV to `SchedaResource` with columns `employee_id`, `evaluation_type`, `year`, plus one column per scoring criterion, to create multiple Scheda records at once.
2. Before committing, the system shows a preview: total row count and a sample of parsed rows.
3. A dry-run mode shows the same preview without writing any records to the database.
4. Rows with missing required values or out-of-range scores/year are reported individually (row number + reason) and excluded; valid rows in the same file still import.
5. On confirmed import, all valid rows are created as Scheda records with `status = "draft"`, and a success message reports the count created.
6. A "Clone previous year" bulk action creates draft Scheda records for the current year by copying employee/evaluation_type from a given prior year's records, leaving scores blank for re-entry.

## Tasks / Subtasks

- [ ] Create `SchedaCsvImporter` parsing CSV rows into validated DTOs, collecting per-row errors (AC: #1, #4)
- [ ] Build Filament import page `ImportScheda` with file upload + preview table (AC: #1, #2)
- [ ] Wire a dry-run toggle that runs the importer without persisting (AC: #3)
- [ ] Create `ImportSchedaFromCsvAction` performing the bulk insert of valid rows inside a DB transaction (AC: #4, #5)
- [ ] Show a success summary (count created, count skipped with reasons) after import (AC: #5)
- [ ] Create `CloneSchedaFromPreviousYearAction` + a "Clone previous year" header action (AC: #6)
- [ ] Feature tests: valid CSV imports all rows; mixed valid/invalid CSV imports only valid rows and reports errors; dry-run persists zero records; clone previous year creates blank-score drafts (AC: #1-#6)

## Testing

<!-- LOCKED. External dev tools must not edit Testing. -->

- **Unit:** `SchedaCsvImporter` row-parsing/validation logic (malformed row, missing column, score out of range, year out of range) independent of the Filament UI.
- **Feature:** well-formed CSV creates N draft records; CSV with 3 valid + 2 invalid rows creates 3 and reports 2 with reasons; dry-run performs zero DB writes but populates the preview; clone-previous-year creates new draft records with blank scores and matching employee/evaluation_type.
- **Fixtures:** sample CSV fixture files (valid, mixed-validity) under `Modules/Rating/tests/Fixtures/csv/`.
- **Edge cases:** duplicate `employee_id`+`year` within the same CSV (reported as a row-level error, not silently overwritten); empty file upload; header-only CSV (zero data rows).
