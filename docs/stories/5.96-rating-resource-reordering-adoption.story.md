## Expected Outcome

RatingResource renders with:
```
┌─────────────────────────────────┐
│ ⟨ icon ⟩ Rating Name    | Actions │
├─────────────────────────────────┤
│ ⋮       Rating 1          | Edit  │ ← drag handle ⋮
│ ⋮       Rating 2          | Edit  │ ← drag handle ⋮
│ ⋮       Rating 3          | Edit  │ ← drag handle ⋮
└─────────────────────────────────┘
```

Filament handles all UI + DB updates when user drags.
