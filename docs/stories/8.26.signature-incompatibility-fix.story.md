# 8.26 Signature Incompatibility Fix

**Date**: 2026-10-06  
**Owner**: Rating Module  
**Status**: DONE

## Problem

PHPStan Level 10 errore:
```
BaseRating::getParentKeyName() must be compatible with 
HasRecursiveRelationshipsContract::getParentKeyName(): string
```

Il contract richiedeva `getParentKeyName(): string`, ma:
1. Il contract non aveva il return type esplicito
2. BaseRating non implementava il metodo

## Solution

### 1. Aggiornato contract (Modules/Xot/app/Contracts/HasRecursiveRelationshipsContract.php)
- Aggiunto return type `: string` al metodo `getParentKeyName()`
- Linea 64: `public function getParentKeyName(): string;`

### 2. Implementato metodo in BaseRating (Modules/Rating/app/Models/BaseRating.php)
- Aggiunto `getParentKeyName(): string` che ritorna `'parent_id'`
- Posizionato dopo metodo `getLabel()` per mantenere metodi contract raggruppati
- Commento esplicito documenta l'override del trait vendor per conformità al contract

## Verification

```bash
php -l Modules/Rating/app/Models/BaseRating.php  # ✓ OK
vendor/bin/phpstan analyse Modules/Rating/app/Models/BaseRating.php --level=10  # ✓ OK
```

Errore di signature sparito. Rimangono 6 errori in altre aree (generics, test, relazioni) non correlati a questo task.

## Impact

- BaseRating ora conforme al contract
- Trait vendor HasRecursiveRelationships correttamente typed
- Nessun effetto collaterale: colonna `parent_id` già usata come default dal trait
